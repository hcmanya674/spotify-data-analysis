# Spotify Data Analysis 🎵

## Project Overview
This project analyzes Spotify's 2023 dataset to understand patterns in music popularity.  
Using Python and data visualization, the project explores how features like BPM and danceability relate to song streams.

## Tools and Libraries Used
- Python
- Pandas
- Plotly
- NumPy

## Dataset
The dataset contains information about Spotify tracks such as:
- Track name
- Artist
- BPM (beats per minute)
- Danceability
- Number of streams

## Analysis Performed
The project performs the following steps:
1. Load the dataset using Pandas
2. Clean the dataset by removing missing stream values
3. Convert stream counts into numeric format
4. Calculate the average number of streams
5. Create a 3D visualization to explore relationships between:
   - BPM
   - Danceability
   - Number of Streams

## Visualization
A 3D scatter plot was created using Plotly to analyze the relationship between music characteristics and popularity.

## Key Insight
The analysis helps explore whether higher danceability or certain BPM ranges are associated with higher streaming numbers.

1. Clone the repository
